# 用反应扩散和局部反馈生成抽象图案，明确数据场、模拟参数和显示材质的关系

- 选择稳定的二维计算网格、固定子步和明确边界条件。将求解网格与输出分辨率分离，用固定种子比较参数。
- 把数据映射到一个可观察的作用位置，例如种子分布、参数缓变场或局部障碍。定义取值范围和无数据区域，保留模拟之外的数据对应关系。
- 先测极端参数，检查计算是否饱和、发散或只剩噪声。长时间运行用有限子步推进，避免帧率变化改变算法结果。
- 以多帧或固定模拟步核对形态。输出时记录种子、步数与模型参数，便于复现同一画面。
