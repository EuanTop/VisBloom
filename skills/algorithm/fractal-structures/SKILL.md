# 用分形和递归几何表达层级、分支或尺度关系，控制停止条件、数值边界和渲染成本

- 明确数据控制的是树的真实拓扑、递归层数、分枝比例还是装饰扰动。没有父子关系时，递归用于造型，实际数据关系保留独立标记。
- 有限深度与最小投影尺寸共同控制停止。按稳定路径派生随机种子，局部变动只影响所属分支。
- 对小分母、对数、指数和幂做定义域检查；迭代保留有效值和最大步数。显示一个可复现的最简轮廓，再叠材质。
- 为同一数据核对稀疏与密集两端，确认画面裁剪和移动后仍能观察层级。大规模形态可先缓存静态分支或按分辨率分级。
