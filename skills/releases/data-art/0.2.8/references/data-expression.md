# Data and expression

Read when deciding what a material means or how a visible relationship can carry it. Do the checks relevant to the request; this is not a report template.

## Locate the relationship

- Establish the unit of observation and entity key before grouping. Repeated rows can mean ordered components, repeated measurements or duplicates; those require different treatment. Preserve order when it is part of the material.
- Distinguish measured quantities, ordinal labels, categories and computed layout positions. A graph layout coordinate is not a physical location; an ordinal rating is not concentration. Check units before converting length, area, speed or time.
- Preserve missing observations separately from known zero/false. Multi-valued categories remain multi-valued unless a deliberate reduction is described. A preview or truncated query is not the full dataset.
- Record the query or derivation that created an association. Co-occurrence is an association at a stated counting grain, not causation. Keep unknown labels unknown instead of borrowing values from nearby records.

## Make the relationship visible

Choose which relationship matters for this work: sequence, change, distribution, proximity, repetition, coexistence, hierarchy or uncertainty. Decide which perceptual relationship will carry it, and what remains artistic variation. Several encodings may be legitimate; a conventional chart is not automatically the destination.

Useful internal checks, without adding explanatory prose to the picture:

- Change one input while holding composition and random seed fixed. Does the intended visual relation change, or only a caption?
- Compare a sparse and a dense entity. Does a material treatment obscure the distinctions that matter?
- Check whether an entity can still be located or read back at the viewing scale the brief requires. Exploration can use selection or detail views rather than labelling everything.
- If a non-monotonic distortion serves the expression, make its status clear in project notes rather than presenting it as a measured scale.

For a local style or layout request, preserve an already established mapping; use this reference only to understand what must survive, not to reopen every data decision.
