# 为 AVA 查询和数据艺术建立字段含义、记录粒度、单位、关联键和缺失规则

- 先说清一条记录对应什么。同一款产品的多条成分记录需要先按产品归组，才能以产品为单位计算覆盖率。明确键是否跨批次稳定。
- 关联前分别检查两侧键的唯一性、空值和重复频率。比较关联前后行数，拆出未命中记录，避免把一对多展开误当新增实体。
- 列出单位、有效范围、时间含义及空值语义。未知、未记录、实际为零和不适用应能在查询与作品中区分。
- 用一条小查询拿到分母、分子和未分类数，检查几条原始记录，再决定衍生字段。保存可复跑的 SQL 和筛选口径。
- 可选的 AVA semantic 定义用来记录口径、提示后续分析。查询或画面需要衍生值时，把表达式写进实际执行的 SQL，并核对计算结果。
