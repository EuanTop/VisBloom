# 组织时间序列、稀疏观测、变化量和时间驱动的艺术作品

- 分别保留观测时刻、记录顺序和播放时钟。带时区的数据先统一时间基准，再计算实际间隔。
- 统计缺测、重复时刻和采样间隔。时间轴上的断点保留实际空档；需要等时长展现时说明使用观测序号。
- 选择合适的比较基准，例如上一帧、固定首帧或同季节。先在 AVA 查询中生成变化量，再由画面决定速度和缓动。
- 如果为交互做插值，保留最近原始观测的时间与读数。离散类别宜按观测切换，连续量插值时避免越过已知物理边界。
