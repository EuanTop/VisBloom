# 设计水墨、渗化墨边、积墨与飞白，适用于需要同时保留数据轮廓的作品

- 先从参考里辨认墨色层次、纸面吸水、干笔断续和留白。让具体笔触决定实现。
- 将数据形态与媒介分层。数据轮廓负责比较，纸齿与笔触沿局部法线、行笔方向或曲率变化，避免同一噪点铺满全部区域。
- 用不同衰减半径叠出湿边与积墨。飞白用方向性稀疏遮罩保留纤维或短裂隙，轮廓辨识困难时收紧渗化范围。
- 锁定图形与随机种子，在作品全貌和原尺寸局部对照。尤其检查密集区域的层次，以及印刷或长图输出中的墨边。
