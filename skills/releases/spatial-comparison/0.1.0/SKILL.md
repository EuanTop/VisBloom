# 按坐标、邻近关系、地理分组和空间尺度构造地图、球面或网格的数据表达

- 先确定坐标系、度或弧度、经度范围和坐标无效的记录。对球面使用角距离；只有明确半径后才换算实际长度。
- 把地理邻近与属性相似分开计算。先定义可比的类别和尺度，再按距离排序。若距离只是同分时的次序，在标注中说明。
- 空间聚合记录网格规则、采样数和投影。跨纬度比较密度时，考虑单元面积差异；空网格应保持其观测状态。
- 保留地点或记录 ID，让画面中的选中项可追溯。通过两条横跨经度边界和靠近极点的记录验证映射。
