# 组织交互科普、翻页、长页和多章节数据作品，并让屏幕状态与导出行为可控

- 使用作品实际支持的文档运行环境。将章节和叙事写在作品模块，内容可以来自数据；导航结构跟随作者已确定的阅读顺序。
- 翻页适合独立场景和保留当前焦点。长页适合并置、回看与连续观察。先明确每个交互改变什么状态，再决定其表达方式。
- 屏幕状态用稳定的章节和选中项 ID 保存。作品被更新时保持有效选中项、滚动位置与键盘焦点；失效时选择可解释的回退。
- 分别验收窄屏、鼠标和键盘。海报模式由作品决定展开哪些章节及状态。原作已有比例、字体和排版时直接沿用。
