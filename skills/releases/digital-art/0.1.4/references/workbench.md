# Make and inspect the work in Visloom

Run commands from the Creator Kit. The examples omit the shared prefix `npm run --silent visloom --`. Use the supplied `ART_WORKBENCH_URL` or the local default and select a specific project throughout.

- `create --name "Work title" --preset blank --renderer renderer.document` creates a blank work. Use `renderer.canvas2d` for procedural marks and drawing, `renderer.three` for live spatial work, and `renderer.document` for DOM, SVG or layered compositions. Check the intended output and available tools before committing to a production route.
- `context --project ID` reads revision, files and recent changes. `file --project ID --path src/artwork.ts` reads one file. Save with `files --project ID --revision N --input edit.json`. The manifest contains `files` entries with `path`, `contentFile` or `content`, and the current `expectedHash` when replacing an existing file. Re-read and reconcile edits if the revision changes.
- Export a named `createArtwork(context)` from `src/artwork.ts`. Canvas returns `{ draw({ctx, width, height, time, parameters}) { … } }`, Three.js returns a scene and can supply `update`, and the document renderer mounts in the supplied `root` and can supply `update`, `ready` and `dispose`. Keep disposable resources owned by the work. Add entries to `controls.json` only when changing a parameter helps the creator. Surface public gestures within the work when they belong to it.
- `preview --project ID --revision N` returns the frozen artwork URL. Open it in the available browser, inspect the rendered image and try any meaningful public action. A connected workbench panel supports `capture --project ID --revision N --out work.png`. Capture a specific moment or state when it matters. Read the PNG with your host’s image tool, or call Visloom’s read-only `artwork_read_capture` tool with the completed capture ID. If the CLI uses a custom service address, configure the same `ART_WORKBENCH_URL` in the host’s Visloom tool environment. A capture path or job status alone doesn’t show the image. Attach the captured PNG when the host requires that handoff.
- `export --project ID --revision N --out work.html` saves the independent artwork. Confirm the exact revision opens and behaves as expected at its intended size. If visual access was unavailable, say which view could still be checked and leave the visual judgment open.
