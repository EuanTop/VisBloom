# Editorial typography

List the actual reading roles: a title, a data label, a value with units, a legend, a note, or the artwork's own words. Merge redundant text roles where possible. Decide which words share a line or attach to a mark. Establish a reading order with position and space, then with weight, size and contrast.

- Test the voice with actual copy. Compare heavy and fine weights or serif and sans-serif at the size that will ship. Choose where a strong contrast helps the hierarchy and where it breaks the continuity. Use regular or tabular figures according to whether prose or numeric comparison matters.
- In Chinese and Latin mixes, judge visible glyph size and baseline by eye in the real font. Check numeral width, full-width punctuation, line breaks around labels, and a long bilingual title. Set appropriate language metadata. Give text its own responsive layout where the work needs reflow.
- Place labels and callouts next to the marks they explain. Check overlap against dense regions, the longest entry, and real values with signs, decimals or units. Give the exact reading a separate detail view when adding all labels would hide the primary pattern.
- Verify fonts and fallback at actual screen and export size, including narrow layout. Use licensed assets with the rights needed for embedding. Preserve author-supplied fonts, copy and layout in a faithful reproduction.

## Type on objects that change

Find the text the object would plausibly carry, such as a date, receipt line or stamp. Give it an actual job in the viewing order. If it establishes an expectation, let the audience read it before the change. If lettering itself changes role, keep an edge, character, line or spacing pattern readable long enough for the audience to connect both uses. Check the opening and defining frame at intended size, then watch the handoff without added explanatory copy.

Sources: [W3C Chinese Text Layout Requirements](https://www.w3.org/TR/clreq/) and [Nadieh Bremer's Space Wars](https://www.visualcinnamon.com/portfolio/space-wars/).
