# 借鉴后现代图形设计的异质网格、断裂层级与错位构成，用于有明确编辑立场的数据作品

- 根据参考找出被有意破坏的结构，例如网格、阅读顺序或字号层级。先定读者需要稳定找到的尺度、单位或作品入口。
- 将编辑性张力放在一个明确层面，例如边注越界、两套对齐关系或异质图形之间的并置。原始尺度和标签关联在反常构图中保持可追溯。
- 区别用于解释数据的主结构与可变的装饰层。相同数据编码遇到旋转、覆盖或挤压时，另设清晰的读取位置。
- 用实际阅读路径检查手机、桌面和海报。确认变形后最难读的数据仍能比较，标题也保留作者的叙事语气。
