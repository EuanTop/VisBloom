# 比较数据分布、样本覆盖和不确定性，决定分组、区间及缺失值如何进入画面

- 比较前固定观察单位和权重。每实体一票与每事件一票回答不同的问题；输出每组有效 N 和缺失数。
- 样本少时保留原始点，样本密集再用统一分箱、分位数或密度。跨组共享分箱边界和轴范围，保留异常点的可查入口。
- 区分数据的散布范围、单次测量误差和对某个统计量估计的不确定性。为每种区间标出含义及适用范围。
- 缺失多的组可用断点、淡色或单独标记呈现可观测范围。若填补值进入计算，记录方法并比较结果对填补规则的敏感度。
