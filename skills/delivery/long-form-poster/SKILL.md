# 从交互长页、图谱或科普作品导出竖版长图，检查完整内容、真实排版与资源就绪

- 先决定海报展示的是当前观察状态还是展开后的完整图谱。沿用作者给出的静态排版与视觉素材。
- 用作品的 poster 模式展开折叠区、调整分页和渲染可打印的图层。选定尺寸应约束内容宽高和像素总量。
- 等字体、图片、WebGL 和 Canvas 层实际就绪再截图。长图至少复核开头、中段、末尾和原尺寸文字细节。
- 完成后核对输出的像素尺寸、比例和可读性。恢复屏幕视图的滚动、选中项和运行状态，保持网页交互版可继续观看。
