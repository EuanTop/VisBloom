与 Agent 继续创作

在工作台点“复制给 Agent”，把内容粘贴到已有对话，再告诉它你想改什么。保持工作台运行，修改会在画面中接上。

让 Agent 开始

复制的信息包括工程目录、项目 ID 和服务地址。让它先读取工程里的 skills/core/data-art/SKILL.md，然后使用项目 CLI：

npm run --silent visloom -- --help
npm run --silent visloom -- context --project 项目ID

先读取当前作品，再继续修改。创作方法在 Skill 中，命令负责执行；默认总览只提供必要信息，源码与数据按需读取。

查询与画面

查询用于分析。只有明确“应用到画面”才会更改作品使用的数据。截图需要当前作品的画布保持打开；导出文件确认完成后再交付。

需要 MCP 的宿主

如果宿主通过 MCP 使用工具，可配置以下服务。它与 CLI 共用同一份项目。

command: npm
args: ["run", "--silent", "mcp"]
cwd: 本工程的绝对路径
env:
  ART_WORKBENCH_URL: http://127.0.0.1:4318

使用 project_context 的 summary 视图读取概览，dataset_inspect 临时分析，dataset_query 应用到画面。配置生效方式以宿主为准。
