Create with your agent

Use a coding agent that can run commands on your computer. The creator kit runs on macOS and Linux with Node.js 22.13 or later.

  1. Send a prompt to your agent

    Paste this into a new chat. Add an idea or the path to your own data, or start with the built-in observations.

    Read https://visloom.euantop.work/skills/visbloom/SKILL.md and help me make my first interactive artwork. Use my local VisBloom setup or help me start one. Ask what I want to make. If I need a starting point, use the built-in Physarum observations. Help me open the draft in the local workbench.

  2. Open your first draft

    Open the workbench link your agent gives you. Try the artwork’s controls or tell your agent what you want to change. The local workbench opens without an account.

  3. Share it when it’s ready

    Export an interactive HTML file. If you want a public link, ask your agent to help publish it to your GitHub Pages.

Install the creator kit yourself

Download and unpack the kit. Run npm ci and npm start in the extracted folder, then open 127.0.0.1:4318.
