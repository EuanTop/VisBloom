# Publish a Visloom project with GitHub Pages

Use the creator's GitHub account and an explicitly intended work repository. A local preview or a request for an HTML file is an export. A request to publish a confirmed version authorizes the public delivery of that version.

1. Identify the project and revision with `npm run --silent visloom -- context --project PROJECT_ID`. Check which data rows and fields are needed for viewing. AVA can prepare a selected result for the work. Keep the original project and complete source dataset in the creative workspace.
2. Run `npm run --silent visloom -- pages --project PROJECT_ID --revision REVISION --out NEW_DIRECTORY`. This stages `index.html`, `cover.jpg` and `.nojekyll` in the same publishing directory. If the capture browser is missing, run `npm exec playwright install chromium` once. Visloom captures the exported page at 1200 × 900 after it renders. For an authored composition or a longer entrance, add `--cover /path/to/chosen.jpg` to use the creator's selected JPEG. Review both the artwork and the cover with the creator before pushing. Check the HTML's embedded viewing payload and include any required public assets.
3. Run `gh auth status` on the creator's machine. If needed, guide the creator through `gh auth login --web` and resume after GitHub authorization. Use the existing session to publish the staged files to the agreed repository. Leave unrelated files, raw data, project source, notes, and credentials in the local environment.
4. Enable GitHub Pages for the publishing branch. Wait for the actual Pages URL to return the expected HTML. Verify a meaningful interaction and an iframe on another origin. Open the lowercase `cover.jpg` next to the live page and confirm it shows the approved view. Return the live URL and the iframe code in the original conversation. To submit to the Visloom gallery, share the public page URL, title and author. The gallery uses the sibling `cover.jpg` when available and keeps a text link for older releases without a cover.

[GitHub Pages publishing source](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
